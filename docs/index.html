ルール

左右に動いて、落ちてくる王冠を頭で受け止める。10個積んだらクリア。制限時間は90秒。

巨大こけしと自由の女神が、積んだ王冠を崩しにくる。小こけしに3回当たったらゲームオーバー。

入力動作
← A左移動
→ D右移動
画面下のボタン左右移動
Space Enter開始（タイトル画面）
巨大こけし直撃。王冠が飛んだ

起動まで

STEP 1

DMG を落とす

上のボタンから OhkanGame-v0.9.0-macos-arm64.dmg を落とす。

STEP 2

Applications に入れる

DMG を開いて、RustOhkanGame.app を Applications に入れる。

STEP 3

初回だけ手で開く

初回は macOS に止められる。公証していない ad-hoc 署名だから。

システム設定 → プライバシーとセキュリティ を開いて、「このまま開く」を押す。
システム設定 → プライバシーとセキュリティ →「このまま開く」

ソースから

clone して cargo run すれば動く。.app の作り方は README に書いてある。

macOS（arm64）。フレームワークは macroquad。当たり判定や攻撃者の動きは、できるだけ AS3 版に寄せてある。
